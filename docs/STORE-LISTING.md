# XboxJellyfish Store Listing

## Short description

An independent, controller-first Jellyfin client for Xbox with a fast 10-foot interface and native playback where Xbox supports it.

## Full description

Bring your Jellyfin library to the sofa. XboxJellyfish is an independent Xbox client designed for gamepad navigation, quick server sign-in, and clear playback controls.

### Highlights

- Browse libraries, search titles, and open media with a 10-foot interface.
- Use Quick Connect to link your Xbox without typing a password on the console.
- Resume Continue Watching items and move through Next Up episodes.
- Choose audio and subtitle tracks during playback.
- Adjust streaming quality for changing network conditions.
- Prefer direct play for Xbox-compatible H.264, HEVC, AV1, AAC, OPUS, and FLAC media.
- Fall back to Jellyfin server transcoding when the media or container is not supported for direct play.
- Trust a self-signed server certificate only after an explicit per-server confirmation.
- Run an in-app API self-check to help diagnose connectivity problems.

XboxJellyfish does not provide media, a Jellyfin server, hosting, accounts, or content. You need access to a Jellyfin server that you operate or are authorized to use. Playback, HDR behavior, transcoding, and performance depend on the Xbox model, server, network, media, and server configuration.

XboxJellyfish is **not affiliated with, sponsored by, endorsed by, or officially connected to Jellyfin**. Jellyfin is referenced only to identify compatible server software. See the project's [trademark disclaimer](JELLYFIN-DISCLAIMER.md) and [privacy policy](PRIVACY.md).
